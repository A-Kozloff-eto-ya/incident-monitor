# Контур — мониторинг инцидентов

Панель для просмотра SSE-потока инцидентов с пакетным обновлением интерфейса, фильтром важности и группировкой по регионам и подразделениям.

## Требования

- Node.js 20.19+ или 22.12+.
- npm.

## Запуск

```bash
npm install
npm run dev:all
```

Откройте адрес Vite, который появится в терминале (обычно `http://127.0.0.1:5173`). Команда `dev:all` одновременно запускает интерфейс и mock SSE-сервер. Vite проксирует `/api/events` на `http://localhost:3001/api/events`.

По отдельности процессы запускаются командами `npm run dev` и `npm run mock` в двух терминалах. Для проверки готовой сборки доступны `npm run build` и `npm run preview`.

## Проверки

```bash
npm run test
npm run build
```

Vitest проверяет разбор и валидацию сообщений, ограничение хранилища, группировку, фильтр и правила подсчёта. С mock-сервером в браузере можно проверить поток, раскрытие узлов, фильтр и живые счётчики.

## Архитектурные решения

- **Жизненный цикл SSE управляется в `useIncidentStream`.** `EventSource` и интервал создаются в `useEffect`. При очистке останавливается таймер, закрывается соединение, отключаются обработчики и очищается очередь.
- **Повторный запуск эффекта в `React.StrictMode` безопасен.** После очистки старые обработчики помечаются неактивными и не могут обновлять состояние.
- **Сообщения обрабатываются пачками.** Они накапливаются в `queueRef`, а раз в 250 мс применяются одним функциональным вызовом `setEvents(current => ...)`.
- **Раскрытие узлов хранится независимо от потока событий.** Открытые регионы и подразделения записаны в `Set`, поэтому добавление новых событий не закрывает раскрытые ветки.
- **Список инцидентов виртуализирован.** В DOM отображаются строки рядом с видимой областью прокрутки, а не вся лента целиком.
